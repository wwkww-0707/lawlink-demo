# 外服法务通：瞬时风控，专家直达

> 东浩兰生“AI来赛”数智化创新大赛 · 赛博革新赛道 · 参赛演示原型
> 上海外服广东公司 · 智法先锋团队

## 打开方式

**直接双击 `index.html`**，用任意现代浏览器（Chrome / Edge / Safari）打开即可，无需安装任何环境。所有交互均可点击操作，首次打开需联网（加载样式库）。

## 原型包含 7 个模块

| 模块 | 说明 |
|---|---|
| 瞬时风控工作台 | 一句话描述用工情形，秒级输出风险等级、风险点与处置建议；含「三道防线 · 人工审核机制」 |
| 智能法规查询增强版 | 512 城属地政策库，输出“本地化适用指引”，切换城市结果实时变化 |
| 类案检索智库 | 判例倾向预判 + 类案清单，支持按年份、法院层级筛选 |
| 7×24 智能咨询 | AI 即时解答带法条引用与置信度，置信度 <85% 自动转人工，复杂问题自动匹配领域专家 |
| 一键生成法律分析报告 | 自动输出风险点清单、法规依据、赔偿测算与时间节点，报告标注「AI 草案 · 待律师复核签发」，可导出 PDF |
| 专家直达 | 五步服务闭环流程、专家库、商业飞轮 |
| 项目概况 | 竞赛信息、立项卡七要素、中期评测指标、知识沉淀资产、孵化里程碑（MS1—MS6）与两级跃迁路径 |

## 对标评审要求的设计

依据《中期答辩具体安排》《项目立项卡（模板）》《项目中期评测报告（模板）》对齐：

- **立项卡七要素**：项目概况页完整呈现业务痛点 / 用户对象 / 输入数据 / 输出结果 / **人工审核点** / **风险边界** / MVP 演示路径
- **人工审核点三道防线**：置信度闸门（<85% 转人工）→ 高危强制专家复核 → 报告律师签发
- **数据指标**：输出准确率 91.2%、引用准确率 87.6%、稳定性异常率 0.8%、演示流畅度自测达标
- **知识沉淀（K8）**：4 项可复用资产（属地差异比对 Skill、类案倾向预判 Skill、报告模板库、分流提示词集）
- **里程碑口径**：对齐 12 周孵化节奏 MS1 启动 → MS2 原型 → MS3 迭代 → MS4 中期评审（第 8 周，当前节点）→ MS5 产品化 → MS6 终审

## 技术说明

- 单文件 HTML 原型（Tailwind CSS + 原生 JavaScript，无后端依赖）
- 演示数据为模拟数据，写死在 `index.html` 底部的 `DATA` 区，可自行修改
- `screenshots/` 内为各模块运行截图，可直接用于申报材料
