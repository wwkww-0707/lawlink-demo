# 外服法务通：瞬时风控，专家直达

> 东浩兰生“AI来赛”数智化创新大赛 · 赛博革新赛道 · 参赛演示原型
> 上海外服广东公司 · 智法先锋团队

## 打开方式

**直接双击 `index.html`**，用任意现代浏览器（Chrome / Edge / Safari）打开即可，无需安装任何环境。所有交互均可点击操作，首次打开需联网（加载样式库）。

## 原型包含 7 个模块

| 模块 | 说明 |
|---|---|
| 瞬时风控工作台 | 一句话描述用工情形，秒级输出风险等级、风险点与处置建议 |
| 智能法规查询增强版 | 512 城属地政策库，输出“本地化适用指引”，切换城市结果实时变化 |
| 类案检索智库 | 判例倾向预判 + 类案清单，支持按年份、法院层级筛选 |
| 7×24 智能咨询 | AI 即时解答带法条引用与置信度，复杂问题自动匹配领域专家 |
| 一键生成法律分析报告 | 自动输出风险点清单、法规依据、赔偿测算与时间节点，可导出 PDF |
| 专家直达 | 五步服务闭环流程、专家库、商业飞轮 |
| 项目概况 | 竞赛信息、落地里程碑与两级跃迁路径 |

## 技术说明

- 单文件 HTML 原型（Tailwind CSS + 原生 JavaScript，无后端依赖）
- 演示数据为模拟数据，写死在 `index.html` 底部的 `DATA` 区，可自行修改
- `screenshots/` 内为各模块运行截图，可直接用于申报材料
